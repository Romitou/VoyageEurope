function calculDureeTransport(distance: Real; transport: TTransport): Integer;

Cette fonction calcule la durée d'un déplacement. Cette dernière sera alors utilisée dans le terminal avec son déplacement associé.

Parameters
distance
Distance du déplacement
transport
Moyen de transport utilisé
Returns

Durée du déplacement

function calculCoutTransport(deplacement: TDeplacement): Real;

Cette fonction calcule le coût total des déplacements effectués durant le voyage, selon les transports utilsées (train, ou bien train et avion). Les détails des coefficients utilisés pour le calcul du coût sont disponibles en commentaire.

Parameters
deplacement
Déplacement effectué
Returns

Coût du déplacement
